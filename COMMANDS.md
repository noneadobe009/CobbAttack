# VAICOM Voice Commands — Everyday Cheat Sheet

How VAICOM calls work: **who + what** — say the recipient (or just have the right
radio tuned) and the command. Examples: "Chief, request launch" · "Texaco, ready
pre-contact" · "Overlord, bogey dope". Numbers are spoken digit by digit:
"Enfield one one".

## Ground crew ("Chief")
- request launch / request startup
- chocks in · chocks out
- connect ground power · disconnect ground power
- connect air supply · apply air
- request repair · request rearming · request refueling
- canopy open / close

## ATC (tower / ground / approach)
- request startup
- request taxi (to runway)
- request takeoff
- abort takeoff
- request departure · cancel departure
- inbound
- request landing · base to land
- request low approach · touch and go
- request azimuth (case: checking in IFR / VFR)
- clear of runway
- cancel approach
- checking in · checking out

## Tanker ("Texaco", "Arco", "Shell")
- intent to refuel / approaching for refuel
- ready pre-contact
- abort refuel
- breakaway (emergency separation)

## AWACS / GCI ("Overlord", "Magic", "Darkstar", "Focus", "Wizard")
- request picture
- bogey dope
- declare
- checking in · checking out
- request vector to tanker / to home plate / to bullseye

## Wingman / Flight ("Two" / "Flight" / "Element")
- attack my target · engage my target
- engage bandits / engage air defenses / engage armor / engage artillery
- cover me · clear my six
- rejoin formation · open formation · close formation
- break left / right / high / low
- check left / check right
- radar on / off · ECM on / off · music on / off
- smoke on
- go to tanker (send wingman to refuel)
- RTB (return to base)

## Carrier ops (SuperCarrier)
- ball (the ball call — "Hornet ball, three point five")
- Clara (can't see the ball)
- request marshal (Airboss module)
- commencing
- see you at ten
- airboss information · airboss weather

## F-14 Jester (AIRIO module)
- Jester has his own huge menu — activated with the AIRIO module; common ones:
  "Jester, tune tower", "Jester, action hook down", radar and nav commands.

## Tips
- One breath per command works best — short and steady.
- If a word keeps coming out wrong in CobbAttack, double-click it in the window
  and teach the correction. Once taught, it's fixed forever.
- The full database is ~600 commands; this sheet is the daily 20%. Anything DCS
  offers in the comms menu, VAICOM has a spoken version of.
